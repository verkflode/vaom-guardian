# Security

VAOM Guardian is a reference implementation, not a production security product (see the README for what it is and isn't, and for the strength of each control). Reports about it are still welcome, especially anything that lets a call execute without the decision it needs, makes a failure read as `allow`, or lets evidence be changed without `verify` noticing.

Please report vulnerabilities privately, through GitHub's **Report a vulnerability** on this repository's Security tab, or by email to hello@verkflode.com. Don't open a public issue for them. You'll get an answer within a week.

Findings about the OWASP Agent Control Standard itself belong upstream, in the [agent-control-standard](https://github.com/GenAI-Security-Project/agent-control-standard) repository.
